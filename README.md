# the weed ホームページ

## フォルダの中身
サイトは上のタブで切り替わる、複数のページでできています。

| ファイル | タブ | 中身 |
|---|---|---|
| `index.html` | トップ | 個人の方・法人の方の入口、緊急の相談窓口 |
| `soudan/index.html` | 困りごとの相談 | 相談できること、ご相談の流れ |
| `soudan/shakkin.html` など5つ | （困りごとの相談の下） | 借金・モラハラ・パワハラ・就職・生きるのがつらいとき |
| `ryokin.html` | 料金 | 3つのプランと、後払い・無料の条件 |
| `business/index.html` | 法人の方へ | 中小企業向けマザーAI（相談後に見積書を送付） |
| `circle.html` | サークル募集 | 一次創作の仲間募集 |
| `column/index.html` | コラム | コラムの一覧（`column/template.html` が記事のひな形） |
| `about.html` | 私たちについて | 企業理念、代表プロフィール |
| `style.css` | | 全ページ共通の見た目 |
| `favicon.svg` | | ブラウザのタブに出る雑草のアイコン |
| `sitemap.xml` | | Googleに渡すページの一覧 |

ページを増やしたときは、全ページの「タブ」の部分（`<nav class="tabs">` の中）に1行足し、`sitemap.xml` にもURLを足してください。

## パソコンで見てみる方法
`index.html` と `style.css` を同じフォルダに置き、`index.html` をダブルクリックするとブラウザで開きます。

## GoogleフォームのURLを変える方法
いまは相談フォームのURLが設定済みです。フォームを作り直したときは、`index.html` をテキストエディタで開き、`docs.google.com/forms` で始まるURL（全ページにあります。テキストエディタの「すべて置換」が便利です）を新しいURLに書き換えて保存します。

## 文章を変えたいとき
`index.html` の中で、変えたい文章を探して書き換えるだけで大丈夫です。`<h2>` や `<p>` などの `< >` で囲まれた部分（タグ）は消さないように注意してください。

## 色を変えたいとき
`style.css` のいちばん上、`:root { ... }` の中にある色（`#3d6b45` など）を変えると、サイト全体の色が変わります。

## コラムを書くとき
1. `column/template.html` をコピーして、`2026-11-01.html` のような名前にします。
2. タイトル、日付、本文を書き換えます。`<meta name="robots" content="noindex">` の1行は消してください（消さないと検索に出ません）。
3. `column/index.html` の一覧に1行足します（書き方はファイルの中の ★ のところにあります）。
4. `sitemap.xml` に記事のURLを足します。

書いた文章をこのスレッドに送ってもらえれば、こちらでページにすることもできます。
