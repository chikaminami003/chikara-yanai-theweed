# the weed ホームページ

## フォルダの中身
| ファイル | 役割 |
|---|---|
| `index.html` | ページの中身（文章・見出し・リンク） |
| `style.css` | 見た目（色・文字の大きさ・並べ方） |
| `docs/企業理念.md` | 企業理念の文案 |
| `docs/Googleフォーム質問案.md` | Googleフォームに入れる質問の案 |

## パソコンで見てみる方法
`index.html` と `style.css` を同じフォルダに置き、`index.html` をダブルクリックするとブラウザで開きます。

## GoogleフォームのURLを変える方法
いまは相談フォームのURLが設定済みです。フォームを作り直したときは、`index.html` をテキストエディタで開き、`docs.google.com/forms` で始まるURL（`★` の印がある2か所）を新しいURLに書き換えて保存します。

## 文章を変えたいとき
`index.html` の中で、変えたい文章を探して書き換えるだけで大丈夫です。`<h2>` や `<p>` などの `< >` で囲まれた部分（タグ）は消さないように注意してください。

## 色を変えたいとき
`style.css` のいちばん上、`:root { ... }` の中にある色（`#3d6b45` など）を変えると、サイト全体の色が変わります。
