# the weed 企業理念（案）

## 理念（いちばん大切な一文）

**どんな場所からでも、人は伸びていける。その力を信じ、ひとりひとりの再出発を支えます。**

雑草（weed）は、アスファルトのすき間や踏まれる道ばたでも、根を張り、花を咲かせます。
わたしたちは、困りごとを抱えた人にも同じ強さがあると考えています。
お金がない、制度がわからない、障碍があるかもしれない。そうした理由で相談をあきらめる人をなくすこと。それが the weed の役目です。

## ミッション（使命）
経済的な事情や障碍の有無にかかわらず、誰もが専門的な相談を受けられる場所をつくります。

## ビジョン（目指す姿）
「相談できる人がいない」という孤立をなくし、困ったときに頼れる根っこが誰にでもある社会。

## バリュー（大切にすること）
1. **否定しないで聴く**：どんな相談も、まず最後まで聴きます。
2. **わかる言葉で話す**：専門用語を使わず、相手に伝わる言葉で説明します。
3. **お金を理由に断らない**：年収100万円以下の方、障碍のある方・その疑いのある方は、コンサルティング料をすぐにはいただきません。
4. **小さな一歩を一緒に喜ぶ**：大きな解決だけでなく、前に進んだ一歩を大切にします。
